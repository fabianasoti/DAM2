Hormiguero

Una página web solo tiene un hilo para pensar y dibujar. Aquí lo puedes ver: cuanto más piensan las hormigas, más se frena todo, hasta que repartimos el trabajo con workers.

Controles

0FPS
0ms de cálculo

Qué estás viendo

  • La carga es lo que cada hormiga "piensa" antes de dar un paso.
  • Con 0 workers, el hilo principal calcula y dibuja: si hay mucha carga, los FPS caen.
  • Con workers, el cálculo se reparte entre varios hilos y el dibujo sigue fluido.
  • Pasarse de workers no ayuda: cada uno cuesta enviar y recibir datos.
