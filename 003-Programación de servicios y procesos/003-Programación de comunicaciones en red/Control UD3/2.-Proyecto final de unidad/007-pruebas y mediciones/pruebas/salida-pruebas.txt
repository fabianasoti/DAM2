Pruebas del chat de sala
Equipo: 8 hilos de CPU, Python 3.12.3, Linux
Las pruebas se hacen en el mismo equipo (localhost), no en una red real.

1. Funcionamiento del chat (servidor TCP)
  OK   el primer cliente recibe su apodo: @apodo invitado1
  OK   un mensaje llega a todos los clientes
  OK   /nick con un apodo válido
  OK   apodo repetido rechazado (sin distinguir mayúsculas)
  OK   apodo con espacios rechazado
  OK   apodo de más de 15 caracteres rechazado
  OK   /usuarios muestra a los conectados: * Conectados: invitado1, ana, invitado3
  OK   comando desconocido avisado
  OK   mensaje de más de 200 caracteres rechazado
  OK   si un cliente se cae, el servidor sigue funcionando
  OK   /salir avisa a los demás: * ana ha salido
  OK   se crea el archivo chat.log
  OK   chat.log recoge conexiones y cambios de apodo
  OK   chat.log no guarda el texto de los mensajes (privacidad)

2. Límite de clientes
  OK   con 3 plazas ocupadas, el cuarto es rechazado: * El servidor está lleno, inténtalo más tarde.
  OK   al salir uno, vuelve a haber plaza

3. Pasarela WebSocket (navegador <-> servidor)
  OK   el navegador recibe su apodo a través de la pasarela
  OK   un comando enviado desde el navegador llega al servidor
  OK   un mensaje de un cliente TCP llega al navegador
  OK   un mensaje del navegador llega a un cliente TCP
  OK   /salir cierra la conexión WebSocket
  OK   sin servidor de chat, el navegador recibe un aviso claro
